# 預購文字批量上架（測試版）

在「訂購管理」打開目前 IP 表單的商品設定，點「文字批量上架」。先貼文字並辨識，再逐項修正作品、國家版本、品項、NT$ 售價、尺寸與版本／影廳。可移除列或手動新增，一批最多 50 項。

```text
蜘蛛人，全部 A3
韓版 A、B、C款各350元
日版全員款450元
美版肖像款500元，特別場
```

以上會整理成五項預購。可辨識現有七種國家版本，北美使用美國國旗。`IMAX A款`、`全員款`等品項可自由命名。「各350」會套用至各款；多款共寫一個金額卻沒寫「各」，會留空要求補填。外幣不會自動換算，請確認後輸入 NT$ 售價。明寫套組的內容保留為一項商品。未辨識的內容會提示核對。

這是本機規則辨識，無需 AI 金鑰或外部文字服務。所有結果必須經使用者確認，辨識過程不寫入資料庫。

點「建立並加入」會建立零庫存預購商品，加入目前表單的待儲存商品清單。接著仍需點「儲存商品設定」或「發佈訂購頁」，客人才會在公開頁面看到這些商品。圖片可透過商品列的鉛筆按鈕補上。

每批以穩定的 request ID 呼叫原子資料庫函式：所有商品一起成功或全部回復。伺服器保存不可修改的批次收據；瀏覽器在結果未確認時保留原輸入與 request ID，網路失敗後按「重試確認這一批」不會再次建立商品。重新整理後，打開同一表單的批次視窗可繼續確認。這個機制不會阻止使用者刻意建立另一個全新批次。

資料庫 `create_preorder_product_batch` 以 SECURITY INVOKER 執行，沿用庫藏權限與結構化商品命名。收據放在 private schema 並啟用 RLS；一般管理員只能操作所屬庫藏，超級管理員可操作選定庫藏。建立批次時固定庫存為 0，不產生現貨 QR 商品碼。

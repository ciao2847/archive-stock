# 商品庫存批量刪除

在「商品庫存」點「批量刪除」，勾選商品或選取目前搜尋結果。一次最多 50 項；超過時可選取前 50 項，其他未勾選商品會在達到上限後停用勾選。切換庫藏、搜尋條件或批量列印模式會清空刪除選取，避免刪到隱藏的搜尋結果。列印選取與刪除選取分開保存。

點「刪除所選」後先顯示所選商品的編號、名稱、庫藏與庫存數量。必須輸入「刪除」才能按「永久刪除」。取消或關閉視窗不會發送請求；送出時鎖定確認與關閉按鈕，避免重複送出。失敗後需重新輸入確認文字；網路失敗導致結果不明時，提示先重新載入商品清單。

沿用既有單筆刪除規則：商品與引用它的完整訂單、包貨、商品 QR、結算紀錄一併清除；同一訂單其他商品的庫存與使用過的商品碼會恢復。確認畫面會明示無法復原。這不是將庫存數量設為 0。

`POST /api/products/batch-delete` 驗證登入、同源操作、UUID、重複 ID 與數量上限，僅呼叫一次 `delete_inventory_products`。資料庫函式以 SECURITY INVOKER 執行，先按照 ID 順序鎖定並確認整批商品權限，再沿用單筆刪除函式。任何一筆失敗都會回復整批商品、訂單與 QR 異動。同庫藏 staff 可用，admin 保留跨庫藏權限，匿名與其他庫藏使用者無法操作。

圖片檔案在資料庫刪除確認成功後清理；清理失敗回傳警告，不會誤報商品刪除失敗。回應遺失或格式不符時，不會自行重試破壞性操作，而會要求先重新載入確認現況。

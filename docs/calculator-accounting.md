# 成本明細、盈餘分帳與 Excel

財務頁沿用雙月帳期。營收取未刪除、已包裝或已出貨且尚未結算的訂單，依包裝時間（無包裝時間時使用建立時間）的台灣日期歸帳。營收為商品成交總額減折扣，不含買家運費。

## 成本與分帳

每筆成本包含日期、分類、項目、台幣金額與選填備註；分類包括商品購入、國際運費、國內運費、平台費、包材及其他。系統以分為單位加總，金額最多兩位小數，日期必須在所選帳期內，每期最多 500 筆。沒有支出可儲存零筆成本，合計為 0。

可新增最多 20 位分帳對象，名稱不可重複，每人的百分比最多兩位小數。設定分帳時比例合計必須為 100%；不設定時盈虧保持未分配／未分攤。盈餘＝營收－成本；虧損也依相同比例分攤，以負數金額表示。分配採最大餘數法，以分為單位處理尾差，餘數相同依畫面順序，分配總額恰等於本期盈虧。

成本與分帳比例在同一筆交易內儲存。每次儲存檢查版本並保留明細與比例的修改快照，避免同時編輯互相覆蓋。舊版成本總額在編輯器呈現為「歷史成本總額」一筆，原數字與附件保持完整；明確儲存後才轉成明細。已結算帳期維持鎖定，不能更動成本與分帳比例。

## Excel

儲存後可按「匯出 Excel」下載目前帳期的 `.xlsx`，範圍可選「本期帳目」或「全部已存帳期」，含四張工作表：

- 收支總覽：帳期、結算狀態、成本版本、營收、成本、盈虧、已分配與未分配盈虧。
- 訂單明細：訂單與商品、數量、單價、商品小計及折扣。訂單營收只列一次，避免多商品訂單被重複加總。
- 成本明細：日期、分類、項目、台幣金額、備註與合計。
- 分帳結果：姓名、比例、分配／分攤金額與合計。

選擇歷史結算帳期也可匯出。已結算訂單收入使用 `settlement_orders` 的鎖定收入；成本與比例使用已鎖定帳期資料。訂單商品名稱來自商品主檔，若主檔後來改名，匯出會顯示最新名稱，金額與數量仍依訂單記錄。「全部已存帳期」包含本庫藏所有已保存成本的雙月帳期，跨期明細標示各自的帳期。尚未保存成本的帳期不會混入。匯出操作不會建立結算，未結算報表明確標示為預覽。匯出只讀取已儲存的資料，未儲存修改不會混入檔案。

## 資料庫與權限

遷移：`20261021083916_itemized_costs_and_profit_sharing.sql`，先套用既有 `calculator_period_accounting` 與 `poster_revenue_settlement`。

在既有 `financial_period_costs` 與 `financial_period_cost_revisions` 新增成本明細與比例 JSON 欄位，沿用現有庫藏 RLS、帳期 advisory lock、樂觀版本檢查及已結算鎖定，不改寫舊成本或結算快照。`save_financial_period_details` 在資料庫推算成本總額；觸發器也驗證直接寫入的明細、比例、日期、重複 ID 與合計。`get_financial_period_report` 驗證庫藏身分並在同一期鎖內讀取匯出資料。
